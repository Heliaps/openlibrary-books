# OpenLibrary Books

A Python script that fetches information about 50 books from the OpenLibrary API, filters books published after 2000, and saves the results to a CSV file.

## Features
- Fetches 50 books from the OpenLibrary API
- Filters books published after 2000
- Only keeps books published after 2000
- Extracts the book title, author, and publication year
- Saves the results in a CSV file

## Requirments
- Python 3
- requests

## Installation

Install the required package:
python -m pip install requests

## Usage

Run the script with:
python books.py

The results will be saved in:
books.csv

## API

This project uses the OpenLibrary Search API.
